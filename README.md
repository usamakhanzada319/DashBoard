# Admin Dashboard

A modern, responsive admin dashboard built with **React.js**, **Vite**, **Tailwind CSS**, and **Recharts**. Features dark mode support, interactive charts, and a clean UI.

---

## Live Demo

[View Live Demo](https://dash-board-110.vercel.app/)

---

## Features

- **Dark/Light Mode** - Toggle between themes with smooth transitions
- **Interactive Charts** - Bar and Line charts with hover effects
- **Fully Responsive** - Works on all devices (mobile, tablet, desktop)
- **Modern UI** - Clean design with Tailwind CSS
- **Fast Performance** - Built with Vite for blazing fast builds
- **Reusable Components** - Modular component architecture
- **Search Functionality** - Global search with mobile support
- **Notification System** - Real-time notification bell
- **User Profile** - Profile management ready
- **Stats Cards** - Key metrics with trend indicators
